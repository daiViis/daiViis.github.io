# Security Policy

## Overview

This repository contains the source code for David Cit's personal portfolio website hosted on GitHub Pages. Security is important even for static websites, and we take all security concerns seriously.

## Supported Versions

This is a continuously updated static website. The current live version is always the latest commit on the `master` branch.

| Environment | Status | Description |
| ----------- | ------ | ----------- |
| Production (daiviis.github.io) | :white_check_mark: | Currently supported |
| Development branches | :warning: | For testing only |

## Security Considerations

This website includes:
- Static HTML, CSS, and JavaScript files
- Contact forms and feedback systems
- Third-party integrations (fonts, CDNs)
- Analytics and tracking scripts

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

### How to Report
- **Email**: [Create an issue](https://github.com/daiViis/daiviis.github.io/issues) with the label "security"
- **Response Time**: We aim to respond within 48 hours
- **Updates**: You can expect weekly updates on the progress

### What to Include
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Suggested fix (if you have one)

### What to Expect
- **Accepted**: We'll acknowledge the issue, create a fix, and credit you (if desired)
- **Declined**: We'll explain why the issue doesn't qualify as a security vulnerability
- **Timeline**: Most issues will be resolved within 1-2 weeks

## Security Best Practices

This project follows these security practices:
- No sensitive data stored in the repository
- All external dependencies loaded over HTTPS
- Regular updates to third-party libraries
- Input validation on all forms
- Content Security Policy headers where applicable

## Contact

For security-related questions or concerns:

Thank you for helping keep this project secure!
