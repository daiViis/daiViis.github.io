Project Spotlight

Feign Deduction Tracker

Feign Deduction Tracker is a premium companion interface for Feign, designed to keep role deductions clear, confidence levels visible, and team communication faster during high-pressure rounds.

View Repository on GitHub

Built with support for the Overwolf ecosystem.

Core Experience

The app turns deduction tracking into a fast and visual workflow, so players spend less time remembering notes and more time deciding the next move.

  • Live suspect tracking with confidence-based role labeling.
  • Quick action controls optimized for in-match use.
  • Clean structure built for readability at a glance.

Why Overwolf

Overwolf enables a seamless overlay context, helping players keep strategy tools accessible while staying focused on the game session.

  • Companion behavior designed around gameplay continuity.
  • Lightweight UI patterns to reduce cognitive overhead.
  • Consistent visual language aligned with this portfolio.

Design Direction

This project follows a modern glassmorphism approach with layered highlights, muted metallic tones, and strong typographic hierarchy to deliver a polished, premium feel without sacrificing clarity.
